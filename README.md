# Database Portfolio — HSBI

**Personal learning portfolio | Mechatronics and Automation Engineering**

Welcome to my database portfolio for the Mechatronics and Automation Engineering programme at **Hochschule Bielefeld (HSBI), Campus Gütersloh**.

This repository documents my learning progress, practical exercises, technical experiments and reflections throughout the database module. It serves as a record of the concepts I have studied and the practical skills I have developed in database design, SQL, data integrity, performance optimisation and analytical databases.

**Author:** Trevor Fidel Nyongesa

---

## About This Portfolio

The portfolio is organised by course modules. Each module has its own README containing an overview, learning objectives, practical work, evidence and key takeaways. Reflections are maintained separately to document my learning experience and progress.

The repository also includes additional resources, practical experiments and collaborative project information.
