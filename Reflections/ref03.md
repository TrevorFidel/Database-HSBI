# Reflection 03 — SQL Query Design, Security, and Performance

## Take-away

Module 3 helped me move beyond simply writing SQL queries to understanding how and why they work. I learned that effective database work involves more than obtaining the correct results; it also requires security, performance optimization, clear query design, and evidence-based evaluation. My main takeaway was the importance of testing assumptions before deciding that a query is correct or efficient.

## What was good?

I found it useful to explore how different SQL approaches can produce the same results while differing in performance and readability. Examining query plans helped me understand how databases execute queries and why efficiency matters. I also learned the importance of using safe SQL practices to improve security and make queries more reliable.

## What was difficult?

I encountered some difficulties working with indexes and understanding how to resolve the issues I faced. Although this was challenging at first, I eventually found a solution with the help of a large language model (LLM). This experience taught me the importance of troubleshooting problems systematically and seeking additional guidance when necessary.

## Exploration and show stoppers

Exploring query plans and comparing alternative SQL approaches helped me understand database performance more deeply. I learned that I should not assume a query is efficient simply because it produces the correct result. Testing different approaches and examining the evidence helped me appreciate the importance of making informed decisions when designing queries.

## Interaction with peers and instructors

During this module, I used available learning resources to improve my understanding of SQL query design and performance. When I encountered difficulties with indexes, I sought help from an LLM to identify possible solutions. This reinforced the value of asking questions, exploring alternatives, and learning from different sources when solving technical problems.

## How did you verify AI suggestions?

I used an LLM to help me troubleshoot the indexing issues I encountered. Rather than treating AI suggestions as automatically correct, I learned the importance of checking proposed solutions against the actual database behavior and available evidence. Comparing query results and examining query plans are useful ways to verify whether a suggested solution works as expected.

## Help and extra work

My main focus was improving my SQL skills by understanding query execution, security, and performance. I used an LLM to help resolve the indexing challenges I encountered and to explore possible solutions. This module encouraged me to become more independent in troubleshooting and to focus on writing SQL queries that are correct, secure, understandable, and efficient.
